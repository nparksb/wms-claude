## Trap found while testing (recorded so the next prober does not misread it)

`PATCH /v3/customerorder/999999999` answered **404, not 405**, while PUT and DELETE on the same id answered
405. SDR resolves the existing entity during argument binding for PATCH (to merge into it), which 404s on a
missing id before the controller's supported-method check runs. **A withdrawn PATCH can only be graded on a
real id**; use an empty `{}` body so a mis-withdrawn verb merges nothing.
