Report served two ways: on-screen HAL `GET /v3/lockOverviewDtoView/search/findByKeyword` (JPQL) + Excel `POST /v3/report/exportLock` → `ReportService.exporLockReport` → repo `findByClientOffsetAndLimit` (native).
