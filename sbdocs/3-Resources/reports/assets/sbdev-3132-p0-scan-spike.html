Scan Spike Harness (SBDEV-3132 P0)

Test values only. Never scan or type a password, a person's name or any personal data. The export keeps only lengths and character classes (digit / letter / punctuation) unless you tick "include full character codes" in section 7, which makes every value recoverable. The on-screen keyboard may learn what you type here, so type test labels, not real ones you would not share.

1. Scans vs typing

Pick a mode, tap the field, then scan or type. Scanning: do not press Enter, and leave at least 2 s between scans. If nothing ends a scan within 0.3 s of its last character, the page closes it ("closed by silence"); if more characters or the suffix then arrive within about 1.5 s, the page re-joins them to that scan and records the stall. Prefix test: first scan at least 5 labels (10 is better) with the scanner's prefix switched OFF using "SCANNING, no prefix set (baseline)", then switch the prefix on and scan with "I am SCANNING". A lead that shows up in both runs comes from the trigger or the wedge, not from the prefix. Typing: press Enter after each value. Aim for 100 scans (30 at the very least) and 30+ typed entries per typing method, realistic label shapes (location, pallet, SKU, tote).
